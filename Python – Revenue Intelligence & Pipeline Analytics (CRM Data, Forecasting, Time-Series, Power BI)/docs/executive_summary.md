# Executive Summary

This project models a CRM opportunity pipeline using a medallion architecture and delivers Power BI-ready datasets for sales, customer, product, and forecasting analysis.

Key insights enabled by the model:

- Monthly pipeline value and weighted pipeline track future revenue risk and coverage.
- Closed-won and closed-lost trends quantify revenue momentum by period.
- Rep-level monthly trends isolate performance differences by manager and region.
- Customer cohort analysis distinguishes new logo acquisition from repeat revenue.
- Product trend analysis shows which product families sustain revenue over time.
- Forecast and win-probability outputs provide forward-looking commercial decision support.

This directly demonstrates CRM and pipeline analytics capability across ingestion, conformance, KPI design, time-series analysis, feature engineering, and BI handoff.
