# Sample Data

Add your own APSIM assets here for demos and ingestion.

Suggested contents:

- `docs/`: APSIM markdown, text docs, or worked examples for RAG ingestion
- `apsimx/`: sample `.apsimx` files for the explain tab
- `csv/`: sample APSIM output CSV files for the summary tab

This folder is intentionally lightweight. It is meant to support a demo workflow and does not ship a complete APSIM documentation corpus or a production data package.
