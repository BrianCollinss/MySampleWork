# Research Publication Visualisations

## Overview

This folder is a curated gallery of selected figures from peer-reviewed papers and conference-style outputs. It is included as a compact sample of scientific communication, visual analytics, and publication-ready figure preparation.

## Demo Context

The folder is not intended to be a complete research project repository. It contains visual outputs that are appropriate to share in a portfolio setting and serves as a companion showcase of publication artefacts.

## What The Project Contains

- `Sample Data Visualiations from Peer-Reviewed Publications.md` presents the gallery with captions
- `Fig1.png` to `Fig13.png` provide the image assets referenced by the gallery
- The figures span research themes such as crop modelling, climate risk, drought analysis, and environmental analytics

## Repository Structure

```text
Sample Data Visualiations from Peer-Reviewed Publications.md
Fig1.png
...
Fig13.png
README.md
```

## Data Assets

- The main reusable asset in this folder is the curated figure set itself.
- Each image is paired with caption text in the markdown gallery so the scientific context is preserved.

## Notes

- This folder focuses on presentation artefacts rather than executable code.
- It is useful when reviewing the style and clarity of publication-ready visual communication.
